# Gelt Product Overview

Gelt is an institutional-grade, zero-cost local algorithmic trading suite designed for Robinhood Agentic Trading via the Model Context Protocol (MCP).

## Key Features

-   **Robinhood Agentic Trading MCP Connector**: Interacts with Robinhood's official MCP server.
-   **Risk Governance Engine**: Enforces position sizing caps, trade limits, and stop-loss rules locally.
-   **Local Execution**: Optimized for local operation with zero cloud API costs.
-   **Shadow Trading**: Paper trading for forward-testing strategies alongside live trading.
-   **Strategy Catalog**: Modular library of trading strategies (e.g., Mean Reversion, VWAP Rebound).

## Product Roadmap

-   **Phase 1-3:** Architecture Scaffolding, Live MCP Integration, Technical Indicators (Completed)
-   **Phase 4:** Market Data Suite & Macro Engine (Planned - FRED API, SEC EDGAR)
-   **Phase 5:** Strategy Backtesting & Portfolio Risk (In Progress)
-   **Phase 6-7:** Strategy Catalog & Trading Plan Engine (Completed)
-   **Phase 8:** Shadow Trading & Forward-Test Engine (In Progress)
