## 🎯 What
Implemented lifecycle deployment requirements for the VM Shadow Daemon as specified in ZAR-191. This included updating `pkg/shadow/daemon.go` to support environment variable overrides for `auto_spawn_orchestrator`, updating the deployment script `deploy/setup-vm.sh` to validate the downloaded binary hash and file existence, and modifying `deploy/gelt-shadow.service` to explicitly set `GELT_AUTO_SPAWN_ORCHESTRATOR=false`.

## 💡 Why
This change ensures that when deploying the shadow daemon in production environments, the orchestrator is not mistakenly auto-spawned in environments where it shouldn't be, satisfying safety and operational requirements. It ensures deployment uses a prebuilt artifact securely via SHA-256 validation.

## ✅ Verification
- `bash -n deploy/setup-vm.sh` passed successfully.
- Added `deployment_test.go` to explicitly verify `GELT_AUTO_SPAWN_ORCHESTRATOR=false` logic and script conditional validation without requiring `systemd-analyze`.
- `go test -race ./pkg/shadow/...` passed successfully.
- `go test -race ./...` passed successfully.

## ✨ Result
The system now safely handles shadow daemon lifecycle deployment while enforcing the `auto_spawn_orchestrator=false` constraint via systemd environments.
