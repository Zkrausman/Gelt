# 🎯 What
Implemented a non-blocking, cancellable background worker (`CryptoVolumeScreener`) in `pkg/data/crypto_volume_screener.go` that polls crypto volume every 15 minutes, compares it to a rolling 24-hour baseline, and emits a structured `VolumeAnomaly` event for >300% spikes.

### Changed Files
- `pkg/data/crypto_volume_screener.go`: The background worker implementation with generation-specific handles.
- `pkg/data/crypto_volume_screener_test.go`: Complete determinisic test suite covering cancellation, isolation, overlapping starts, and baseline behavior.
- `docs/specs/ZAR-165.md`: This completion report.

# 💡 Why
To identify sudden surges in cryptocurrency trading volume that exceed a 300% spike compared to the 24-hour rolling average baseline, while adhering strictly to read-only constraints without executing broker orders.

# ✅ Verification
The implementation provides safe `Start`/`waitFn` transitions during concurrent worker restarts, guaranteeing strict restart/join lifecycle serialization. A `waitFn` for a previous generation will properly block until its generation gracefully completes regardless of concurrent restart races. It also properly clones and sorts array inputs to prevent baseline racing or mutation leaks.
