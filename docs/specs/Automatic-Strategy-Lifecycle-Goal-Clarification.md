# Product-goal clarification

The owner requested that the existing roadmap explicitly retain automatic
promotion of qualifying strategies into live trading, automatic demotion or
stopping, and no routine manual per-strategy management. The owner also requested
that implementation remain unplanned.

Changed files are `docs/ROADMAP.md` and this documentation closeout. The new
future-goal section preserves the surrounding roadmap and historical backlog.
It creates no tasks, selects no thresholds and claims no performance or runtime
acceptance. Evidence, exposure/loss limits, rollback and shutdown remain later
design requirements. Current simulation/research scope and G05/G06 holds remain;
real-money activation and financial transactions require user handoff.

Verification is limited to the complete documentation diff, whitespace and
repository identity/status checks before fresh independent and adversarial
reviews. Existing applicable remote checks will be inspected on the exact
reviewed candidate and integrated merge. No held local runtime/probe, model,
broker, account or accepted-job rerun is part of this change. Final publication
evidence belongs in the pull request and delivery receipt.
