# Specification & Completion Report for ZAR-206

## 🎯 What

Harden Gelt's repository-owned Pi subagent fleet for local and VM-assisted configuration review without web search or generic shell authority.

- Disable only Pi's built-in `researcher` at project scope.
- Retain `documentation-researcher` for repository and parent-supplied sources.
- Add read-only `repository-scout` and `vm-readiness-auditor` roles.
- Remove shell access from every project role, including `bounded-implementer`.
- Track reviewed project settings while preserving ignores for all Pi runtime state.

## 💡 Why

The project does not have web-search capability, and generic shell access conflicts with role boundaries that prohibit network, credentials, broker/MCP, service-control, and trading actions. VM configuration work must remain human-operated and evidence-led.

## Implemented Behavior

- `.pi/settings.json` uses `subagents.agentOverrides.researcher.disabled: true`; no override disables `documentation-researcher`.
- Eight project roles are discoverable. Only `bounded-implementer` can edit/write; all roles are shell-free.
- `repository-scout` is read-only and repository-only.
- `vm-readiness-auditor` analyzes approved safe repository paths and human-provided redacted VM command output; it cannot execute VM commands or operate services.
- Parent sessions retain operational, Git, Linear, merge, release, and validation authority. The bounded writer returns parent-run validation commands.

## ✅ Verification

- `subagent({ action: "list" })` showed all eight project roles and no built-in `researcher`.
- `go test -race ./...` passed.
- `go vet ./...` passed.

## ✨ Result

Gelt ships a project-scoped, shell-free Pi fleet that can analyze local repository evidence and redacted VM configuration evidence without enabling web research or autonomous VM operations.
