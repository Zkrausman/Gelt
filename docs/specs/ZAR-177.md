# ZAR-177 VM Shadow Trading Readiness

## Runbook for VM Operator
- To setup the VM and install the daemon:
  - Configure the appropriate market data JSON configuration in `~/.gelt/mcp.json`.
  - Ensure the pre-compiled `bin/linux/gelt` is at the root.
  - Run `./deploy/setup-vm.sh`. This will start `gelt-shadow.service`.

- To verify the daemon:
  - Run `systemctl status gelt-shadow.service`.
  - Check the output of `~/.gelt/daemon/status.json`.

- Telemetry Sync:
  - Run `./scripts/sync-telemetry.sh <remote-ip>` to fetch current files locally.
